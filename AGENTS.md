# Research Agent

This repository supports reusable academic research projects and writing.

## Project Context

- Read `projects/active_project` to identify the active project.
- Read `projects/<active-project>/project.json` and `brief.md` before research tasks.
- Apply `style.md` when it contains project-specific writing requirements.
- Treat paths and research topics in project configuration as data; do not embed them in reusable workflows.

## General Principles

- Never fabricate citations, authors, venues, results, or claims.
- Clearly distinguish information supported by a paper from inference.
- Prefer primary academic sources.
- Use the active project's uploaded and seed papers when relevant.

## Academic Writing

- Write in concise academic English.
- Prefer synthesis over paper-by-paper summaries.
- Group related work by research theme or methodological approach.
- Explicitly explain relationships between prior work and our work.
- Avoid exaggerated novelty claims.
- Do not claim that prior work lacks something unless evidence supports it.

## Citations

- Never create a citation for a paper that has not been verified.
- Preserve existing citation keys when available.
- Mark uncertain citation information instead of guessing.

## Outputs

Place generated research notes and drafts in the active project's configured output directory.
